# Employee Performance Dashboard

## 📌 Project Overview

Employee Performance Dashboard is a SQL project designed to analyze employee performance, attendance, KPIs, project completion, ratings, departments, and other employee-related information.

## 🛠️ Technologies Used

- MySQL
- SQL
- CSV
- GitHub

## 🎯 Objective

The objective of this project is to analyze employee performance data using SQL and generate meaningful insights related to employee KPIs, attendance, project completion, ratings, departments, and performance.
